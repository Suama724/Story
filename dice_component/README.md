# Story 骰子部件

源码运行需要 Node.js 22 或更高版本。首次准备时从项目根目录运行 `npm ci --prefix dice_component`。Windows 打包脚本会把 Node 和固定版本的 BCDice 放入安装目录。

部件通过标准输入输出的逐行 JSON 调用 BCDice。Story 提供本次检定需要的属性和规则设置，管理频道权限、骰娘发言、KP 暗骰和历史重发。

| 聊天输入 | 用法 |
|---|---|
| `.r 2d6+3` | 通用骰式，可在空格后附原因 |
| `.ra 侦查` | 从卡读取技能或属性 |
| `.ra b 困难侦查` | 投一颗奖励骰，要求困难成功 |
| `.ra p2 手枪` | 投两颗惩罚骰 |
| `.ra 斗殴+10` | 本次检定临时增加 10 点 |
| `.ra 闪避 @角色名` | KP 代投公开检定 |
| `.ra 60 @怪物名` | KP 手动指定检定值和名称 |
| `.rh 1d100` | KP 私下投通用骰式 |
| `.rah 侦查 @角色名` | KP 私下代投检定 |

攻击、闪避、反击和伤害可以分别掷骰，由 KP 裁定，结果不会改写人物卡。KP 可在「掷骰管理」选择「村规」为本团设置大成功和大失败区间。
